# 💱 Currency Converter App (React Native)

A simple and responsive mobile app built with React Native and TypeScript that allows users to convert currencies between different countries using live exchange rates.

---

## 📱 Features

- 🌍 Convert between major world currencies
- 🔄 Live exchange rate fetching via API
- 🎯 Simple, user-friendly interface
- 🌗 Optional light/dark mode toggle
- 🎨 Styled with NativeWind and custom components
- 📦 Modular code with reusable dropdown component

---

## 🛠️ Tech Stack

- [React Native](https://reactnative.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Expo](https://expo.dev/)
- [NativeWind (Tailwind for RN)](https://www.nativewind.dev/)
- [react-native-modal-dropdown](https://github.com/sohobloo/react-native-modal-dropdown)
